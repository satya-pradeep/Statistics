A. Descriptive Statistics

Describes the data that you already have.

Examples:

Mean			: sum of observations/no of obs

Median			: Middle value after sorting : 3

Mode			: most frequently repeated val

Variance		: Tells how far the data is from mean

var = sigma[(x-X)**2]/n 
x = value
X = mean
n = no of observations

if std is high : data is far from mean
else: data is near to the mean

Skewness		: Tells about asymmetricity of the data

1)Positive skewness	:Right tailed(mean > median)
	skewness > 0
2)Negative skewness	:Left tailed(mean < median)
	skewness < 0
3)No skewness		:Normally distributed(symmetrically) : (Mean = Median)
	skewness = 0

IQR - Inter-quantile-range : used to handle outliers
step 1 : Q1 : 25% quantile, Q2 : 50% - median, Q3 : 75% quantile

data = [1,7,8,101,2,3,2,34567890,-765432,7,8,4.4] = [-765432,1,2,2,3,4.4,7,7,8,8,101,34567890]
Q2 : 5.7, Q1 : 2, Q3 : 8

step 2: finding IQR:Q3 - Q1 = 6

step 3: finding higher fence : Q3 + IQR*1.5 = 8 + (6*1.5) = 17

step 4: finding lower fence : Q1 - IQR*1.5 = 2 - (6*1.5) = -7

step 5: outliers: lower then LF and higher then HF = -765432,101,34567890(i for i in data if i < LF or i > HF)

outlier_free_data : data > LF and data < HF
